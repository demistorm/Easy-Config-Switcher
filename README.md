# Easy Config Switcher
A simple tool to backup and switch between config profiles!

Works particularily well for performance presets or resourcepack styles.

### Creating Presets:
1. Have all Minecraft options/shaders/resourcepacks/mod settings
configured to your liking. 
2. Go to Easy Config Switcher's config in the Mods screen
   *(requires Mod Menu on Fabric)*.
3. Simply type in a preset name and press "create preset".

The preset with the given name should now appear on the titlescreen!
### Using Presets:
1. Click the desired preset on the titlescreen *(or apply and restart in settings)*.
2. Press "Confirm?"
3. The game will shutdown and switch the config files over to the preset.
4. Start the game again and viola, the preset should have changed and all settings switched!
### Updating Presets:
1. On a fresh launch, make your desired changes. 
2. Go to the config screen and decide if you want to apply those changes to all presets (update the "base" preset) 
    or only a specific preset (choose that specific one). Keep in mind that updates can be 
    applied to any preset (it only updates the preset with the changes since launch).
3. Click the update button on the chosen preset (looks like a pencil).

### Extra Details:
- Up to 10 presets can be added, although the menu can start looking funny after 6 or 
so depending on name length.
- Preset names are capped at 15 characters to prevent issues.
- The text above the presets (default: Easy Config Switcher) can be customized in the bottom
left.
- Preset tooltips can be customized in the settings.
- The starred preset is considered the "Base" preset which contains a full copy of the saved configs.
- When a base preset exists, the rest of the presets are derivative presets (they only contain the changes 
  compared to base).
